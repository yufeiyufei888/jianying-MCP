# 兼容性与测试边界

## 当前范围

- Windows、Python 3.12；剪映 **11.5.0.14471**。不是任意剪映版本通用接口。
- 旧平面明文 schema **360000**，包括两个内容文件逐字节一致的 `flat-mirrored-360000`；已识别 `Timelines/project.json` 的**单活动时间线**保存状态。双文件不一致时停止，不用修改时间猜测；活动时间线存在时绝不退回旧根 JSON。
- 非明文内容使用固定 jy-draftc v0.1.1 和本机 DLL 的暂存适配，原文件不直接作为转换输出。
- 普通连续 1× 正向主轨局部操作；原片字幕允许可验证的恒定正向速度。倒放、曲线变速、复合片段、多时间线及未知工程依赖拒绝写入。
- 生产转场仅来自本机原生验收记录；资源枚举不是可用证明。现有适配测试叠化及闪白，不保证所有候选资源都存在，不自动下载或开通会员。
- 底部字幕：横屏后端字号 5、竖屏 9、白字黑描边、约 `y=-0.8`、最大行宽 82%。具体本机画幅仍需查看、编辑、保存重开确认。

## 已有证据与新安装

开发基线曾在上述锁定版本完成五组原生试验：最新保存读回、局部修改／联动、BGM／新增转场、两类 SRT／横竖屏，以及合成素材重链接。记录包含独立副本的打开、播放、保存、重开和原稿／媒体未变检查；听感由用户实际试听确认，未把音轨可见当试听证据。

本次公开版新增共享启动配置和可移植入口，自动测试／干净检出／真实 SDK 只读传输可以验证这些改动；**没有用这些检查替代新路径下的原生写入验收**。发布时不携带旧通过记录，生产能力默认关闭。每一位安装者必须依照 [native-acceptance.md](native-acceptance.md) 验收自己的构建、后端、资源、路径和代码指纹。

## 可重复验证的方法

1. 白名单及私有路径／常见凭据格式检查：`scripts/validate_release.py`。只扫描公开文件，不扫描原片或整盘；不能证明不存在所有格式的秘密。
2. 自动套件：保留原 108 项，增加配置与公开边界测试。完整报告以测试进程实际输出及 [CI](https://github.com/yufeiyufei888/jianying-MCP/actions) 为准。
3. 原11引用回归：依赖单独安装的修复后端。CI 无该依赖时 11 项显式跳过；3 项真实后端集成也跳过。符号链接权限不足时另有2项跳过。
4. 固定 SDK 真实 initialize、恰好六工具发现、doctor/list/inspect/verify 只读调用：`smoke_readonly.py`。临时合成元数据前后相同，未注册服务、未写实际草稿。
5. 本机原生门禁、生产 SDK 副本写入、最终试听和导出：本地人工验收，不在 CI 中推定。

进程状态检测使用 Windows 系统进程快照，不启动 PowerShell／窗口。快照失败、枚举异常或句柄错误均停止，不能误当“剪映已关闭”。新增测试覆盖全部实例、正常空列表、创建／枚举失败以及不启动 shell。它仍不能保证用户不会在检查后重新启动剪映。

## 小范围兼容修复

- 双明文源同时绑定两个文件指纹，副本同步写入二者，未知字段、片段 ID 和原轨道仍完整保留。生产写入额外要求该构建的双文件副本打开、播放、保存、重开证据；五组基础验收不能自动代替它。
- 平面、双明文及嵌套读回使用同一依赖白名单。外部字体及已验证效果缓存需绑定；目录只允许经过验证的效果字段，内部资源需适配器绑定及预算，不允许任意路径。
- 只有平面草稿元数据中精确相对值 `draft_cover.jpg`／`draft_cover.png` 可作为缺失的可再生目录缩略图列出，不伪造封面。绝对路径封面、画面资源、其他名称和嵌套依赖仍必须存在；缩略图在计划后出现会使计划失效。
- 11.5 保存读回允许完整 `extract_music` 音频材料长度精确向上对齐工程帧网格（最多一帧），仅在材料身份、路径、类型一致时有效。片段入出点、时间位置、音量及未知字段仍精确校验，不提供泛化误差容忍。
- 空或缺失的效果路径不能充当缓存等价证明。

这些修复新增自动覆盖双文件冲突、活动时间线优先级、两个文件及缓存变化、音频舍入边界、缺失封面与未知依赖。开发机有相应短副本原生读回及用户试听证据，但公开版不携带通过记录，新安装仍从未验收开始。

Windows CI 不下载视频、BGM、第三方后端或 codec，不启动剪映。没有“在 CI 中通过原生剪辑”之类承诺。程序无法完全消除用户重新启动剪映造成的竞争；发布期间必须保持它彻底退出。
