# 回滚 / Rollback

先停止客户端对本服务的调用并彻底退出剪映。使用**注册时相同的工具、配置和工作目录**：

```powershell
py -3.12 -I -B -X utf8 .\scripts\jianying_local\setup_mcp.py rollback --config .\config.local.json
```

回滚根据本地注册回执，仅删除本工具拥有且未被手工改写的 `jianying-local` 配置块。其他服务、后加设置、原片、配乐、草稿、用户精剪结果和虚拟环境都保留。注册块被修改、回执不明或配置竞争时停止；不要整份恢复旧备份覆盖新设置。

配置和索引备份、失败回执保留在 `work_root`；恢复索引或旧工具版本须单独核对当前状态，不强推、不覆盖原工程。代码版本回退不能让历史过期计划自动重新有效。

清理 SDK 环境或便携程序是独立的可选操作，先测量、核对确切目录及是否仍被使用，需用户明确同意后再做。本脚本不会删除它们，也不删除生成过的草稿。
